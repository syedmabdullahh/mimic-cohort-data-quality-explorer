# Data Manifest

## Primary dataset (not yet loaded into this build — see README §4)
- **Name:** MIMIC-IV Clinical Database Demo v2.2
- **Publisher:** PhysioNet / MIT Laboratory for Computational Physiology
- **URL:** https://physionet.org/content/mimic-iv-demo/2.2/
- **DOI:** https://doi.org/10.13026/dp1f-ex47
- **License:** Open Data Commons Open Database License v1.0
- **Access:** Open, free PhysioNet account required, no CITI training/DUA
  for the demo subset
- **Retrieval date:** not yet retrieved (network-restricted build sandbox;
  see README §6 for the honest evaluation limitation this creates)
- **Fields used:** subject_id, gender, anchor_age, anchor_year,
  anchor_year_group, dod (patients); subject_id, hadm_id, admittime,
  dischtime, deathtime, admission_type, admission_location,
  discharge_location, insurance, language, marital_status, race,
  hospital_expire_flag (admissions); subject_id, hadm_id, seq_num,
  icd_code, icd_version (diagnoses_icd); icd_code, icd_version, long_title
  (d_icd_diagnoses); labevent_id, subject_id, hadm_id, itemid, charttime,
  valuenum, valueuom, ref_range_lower, ref_range_upper, flag (labevents);
  itemid, label, fluid, category (d_labitems); transfer fields for
  transfers; icustays fields for icustays.

## Schema reference (used, not patient data)
- **Name:** MIT-LCP mimic-code repository, PostgreSQL build script
- **URL:** https://github.com/MIT-LCP/mimic-code (file:
  `mimic-iv/buildmimic/postgres/create.sql`)
- **Retrieval date:** 2026-08-07 (this build)
- **License:** MIT License (mimic-code repository)
- **Use:** table/column definitions only, to build `src/schema.py` and the
  synthetic placeholder generator. Contains no patient data.

## Synthetic placeholder data (bundled in this repo)
- **Name:** Generated by `scripts/generate_synthetic_data.py`
- **Generation date:** 2026-08-07
- **Contents:** 100 synthetic patients, schema-identical to MIMIC-IV Demo
  v2.2, with a fixed random seed (42) for reproducibility and 8
  deliberately seeded, documented data-quality issues
  (`data/synthetic/seeded_issues.json`)
- **NOT real patient data.** Contains no information derived from any real
  individual.
- **Purpose:** allows the prototype to run and be evaluated before/without
  access to the real, credentialed dataset.

## External libraries (no patient data, standard OSS licenses)
- pandas, numpy, scikit-learn — data handling and robust-statistics /
  outlier detection
- streamlit — UI
- pytest — testing

No data was sent to any third-party API or service at any point in this
build or in the running application.
